# chie-lab

ここは、各自が自由にリポジトリを作って、勉強したことや試したことを置いていくためのOrganizationです。  
何をやっているのかがゆるく見える場所になればいいなと思っています。

## 目的

- 自由に学習用・検証用のリポジトリを作る
- お互いの勉強内容や試していることがなんとなく分かるようにする
- 必要に応じて共同開発や共同学習にも使えるようにする

## 使い方

基本的に、自由にリポジトリを作って使ってください。

個人での勉強、検証、試作などに気軽に使ってもらって大丈夫です。  
共同で開発・勉強したい場合は、[TEMPLATE-REPOSITORY](https://github.com/chie-lab/TEMPLATE-REPOSITORY) も利用できます。

[TEMPLATE-REPOSITORY](https://github.com/chie-lab/TEMPLATE-REPOSITORY) では、たとえば以下の仕組みを使えます。

- `main` ブランチ保護を前提にした運用
- コミットメッセージのプレフィックスを強制する Git hooks

必要なら取り込んで使ってください。

## ルール

- GitHub Actions は無料枠の範囲で自由に使って大丈夫です
- このOrganizationでは決済情報を登録していません
- そのため、無料枠を超えた場合は実行されなくなる想定です

ゆるく自由に使いつつ、他の人も使いやすい形で運用できればと思っています。
